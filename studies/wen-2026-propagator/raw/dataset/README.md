# Direct experimental test of Feynman's path integral postulates with single photons

## Description of the data and file structure

### Files and variables

#### File: Fig3.xlsx

**Description:** Experimental result for the test of Postulate I.

##### Variables

* **x_f/**&#x3B4;**x-theor. :&#xA0;**&#x53;patial positions of theoretical results (horizontal axis).
* **P_q(x_f)-theor. :&#xA0;**&#x54;heoretical predictions of probabilities P~q~(x~f~), in arbitrary units (a.u.).
* **P_c(x_f)-theor. :&#xA0;**&#x54;heoretical predictions of probabilities P~c~(x~f~), in arbitrary units (a.u.).
* **x_f/**&#x3B4;**x-exp. :&#xA0;**&#x53;patial positions of experimental results (horizontal axis).
* **P_e(x_f)-exp. :&#xA0;**&#x45;xperimental results of probabilities P~e~(x~f~), in arbitrary units (a.u.).
* **P_q(x_f)-exp. :&#xA0;**&#x45;xperimental results of probabilities P~q~(x~f~), in arbitrary units (a.u.).
* **S.E. of P_q(x_f)-exp. :** Standard errors of the experimental probability P~q~(x~f~).
* **P_c(x_f)-exp. :&#xA0;**&#x45;xperimental results of probabilities P~c~(x~f~), in arbitrary units (a.u.).
* **S.E. of P_c(x_f)-exp. :** Standard errors of the experimental probability P~c~(x~f~).
