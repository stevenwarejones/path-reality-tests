## Completion criteria

- Exact boundary: mathematical construction and computational checks present;
  Lean proof verification pending.
- Auditable Wen example: implemented through observable pointer differences and
  conditional reference division; unavailable calibration inputs named explicitly.
- Informative measurement: conditional finite-menu recommendation implemented;
  unrestricted and invariant-setting impossibility certificates included.
- Final software gate: empirical CI and formal final-head audit/report must pass
  before removing draft status. A green software gate cannot certify the missing
  apparatus assumptions.
